# Baterias Cunha - Site Oficial

Site oficial da Baterias Cunha, especializada em baterias automotivas premium para carros, motos, caminhões, barcos e sistemas solares.

## 🚀 Tecnologias Utilizadas

- **React 19** - Framework JavaScript
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Framework CSS
- **Vite** - Build tool
- **React Router** - Roteamento
- **Remix Icons** - Ícones

## 📦 Instalação e Execução

### Pré-requisitos
- Node.js 18+ 
- npm ou yarn

### Instalação
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/baterias-cunha.git

# Entre no diretório
cd baterias-cunha

# Instale as dependências
npm install

# Execute em modo desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## 🌐 Deploy

### GitHub Pages
1. Faça push do código para GitHub
2. Ative GitHub Pages nas configurações do repositório
3. O deploy será automático via GitHub Actions

### Vercel
1. Conecte seu repositório no [Vercel.com](https://vercel.com)
2. Deploy automático a cada push

### Netlify
1. Conecte seu repositório no [Netlify.com](https://netlify.com)
2. Deploy automático configurado

### Hospedagem Tradicional
1. Execute `npm run build`
2. Faça upload da pasta `out` para seu servidor

## 📁 Estrutura do Projeto
